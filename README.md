# Olá! Eu sou o Nicolas...

Sou desenvolvedor **fullstack**, com foco em **back-end**, apaixonado por tecnologia e comprometido com a evolução contínua por meio de estudos, prática e aprimoramento técnico.

Atualmente trabalho com **Golang** e **PHP**, mas também tenho experiência com:

- Linguagens como **C#**, **Java**, **Node.js**, **JavaScript**
- Frameworks como **CodeIgniter**, **ASP.NET**, **Spring** e **Gio**
- Bancos de dados como **MySQL**, **PostgreSQL**, **SQLite** e **SQL Server**
- Tecnologias de front-end como **React**
- Ferramentas e ambientes como **Docker**, **Visual Studio**, **PhpStorm**, **IntelliJ IDEA**

Estou sempre em busca de novos desafios e oportunidades para crescer como desenvolvedor.
